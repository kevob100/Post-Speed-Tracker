Drop RotoWire NFL's X Analytics exports here (analytics.x.com, @RotoWireNFL, account
overview, export as CSV, daily rows). The pipeline reads every .csv in this folder and
walks the daily new follows / unfollows back from the follower counts it has saved since
Oct 1, 2026, to fill RotoWire's follower history on the Audience view. Files can overlap;
the latest file wins for a date.
